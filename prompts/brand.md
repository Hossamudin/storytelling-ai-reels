# Brand Kit — Hossam El-Din Hassan (حسام الدين حسن)

Applies to every scene, prompt, caption, and composition. Never violate.

## Palette (Tropical Fruit Punch)
| Token  | Hex     | Use |
|--------|---------|-----|
| punch1 | #136052 | Deep teal — primary surfaces, Arabic headlines |
| punch2 | #437F3E | Green — secondary elements, workflow steps, supports |
| punch3 | #B3CE65 | Light green — labels, soft highlights |
| punch4 | #FFEC5C | Yellow — glow cores, emphasis flashes |
| punch5 | #FF5A33 | Orange — THE accent: beams, keywords, CTAs, energy |
| white  | #FFFFFF | Backgrounds (premium editorial), caption base on dark |
| black  | #0D0D0D | Text on light, deep contrast |
| red    | #D93A2B | Sparingly, professional contrast only |

White, black, red used sparingly and professionally for caption contrast.

## Typography
- Arabic: **Noto Kufi Arabic** (one consistent professional font everywhere).
- Latin / English keywords: **Manrope**.
- Clear size/weight staging for reveal sequences. RTL correctness (`dir="rtl"`) for Arabic text.

## Aesthetic
- Minimal 2D vector, premium Apple/SaaS editorial look. Precise geometric alignment, generous negative space.
- Layered composition with clear z-depth (background grid → mid figures → foreground text) to support parallax motion.
- Instant message readability. No visual clutter.

## Hard avoids (default style)
English text in Arabic-first frames, realistic people (unless a Hossam image is used deliberately), robots, computers, offices, money, blue, purple, glitch artifacts, literal particle effects in stills, black backgrounds (unless a dark scene is explicitly chosen).

## Quotes / attribution
Quote cards attribute to "حسام الدين حسن" with the brand palette, professional typography, animated reveal.
