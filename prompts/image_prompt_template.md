# Image Prompt Template (Motion Graphics hero frame)

Adapt placeholders per scene. Keep the structure: layout → central metaphor → typography choreography → style & palette → avoid list. This is the house style for a premium AI-editorial hero frame.

## Image prompt:

Ultra-clean premium AI editorial motion graphic, {aspect}, 4K. Design as a sequenced storyboard frame — a single hero composition built with distinct animatable layers (background, grid, human figure, AI core, beam, typography, icon) so each element can move independently in after-effects/motion design.

**Background & Depth**
Warm off-white base with a subtle 3D perspective grid in Tropical-Fruit-Punch-1 (#136052), low opacity, fading toward the center. Grid lines drawn with slight parallax depth (foreground lines slightly bolder/closer, background lines thinner/farther) to suggest a receding floor or wall plane — built for a slow push-in or grid-scroll animation.

**Central Metaphor (built for motion)**
Left: abstract human silhouette in Tropical-Fruit-Punch-1 (#136052), constructed from a few clean geometric segments (not one flat blob) so it can subtly assemble, pulse, or shift weight in animation.
Right: AI core as a cluster of geometric nodes in Tropical-Fruit-Punch-2 (#437F3E) linked by thin lines, with 2–3 nodes in Tropical-Fruit-Punch-5 (#FF5A33) designed to look like they can pulse, light up in sequence, or rotate slightly, like a living network rather than a static icon.
Center: a bold two-way beam in Tropical-Fruit-Punch-5 (#FF5A33) with a Tropical-Fruit-Punch-4 (#FFEC5C) glow core, drawn as a segmented or particle-trail-style line (no actual particle effects in the still — just implied motion via directional gradient streaks) so it reads as energy flowing both ways between figure and core.

**Typography Choreography** (render Arabic EXACTLY as written, Noto Kufi Arabic)
Headline "{HEADLINE_AR}" in Tropical-Fruit-Punch-1 (#136052) or black, positioned to animate in first (fade/slide up).
"{SUBHEADLINE_AR}" in Tropical-Fruit-Punch-5 (#FF5A33), largest visual weight, staged to punch in second with emphasis (scale-in or color flash).
Ascending workflow "{STEP1}" → "{STEP2}" → "{STEP3}" → "{STEP4}" in Tropical-Fruit-Punch-2 (#437F3E), each stage connected by orange (#FF5A33) arrow nodes designed to light up sequentially, like a progress path animating upward.
Target icon in Tropical-Fruit-Punch-5 (#FF5A33) with "{LABEL_AR}" label in Tropical-Fruit-Punch-3 (#B3CE65), positioned as the final payoff element — built to animate last with a small bounce or ring-pulse, like a goal being hit.

**Style & Palette**
Minimal 2D vector, premium Apple/SaaS editorial aesthetic, precise geometric alignment, generous negative space, layered composition with clear z-depth (background grid → mid figures → foreground text) to support parallax motion. Palette strictly from #136052, #437F3E, #B3CE65, #FFEC5C, #FF5A33, plus white/black/red used sparingly and professionally for caption contrast.

Message must read instantly: {ONE_LINE_MESSAGE}.

Avoid: English text, realistic people, faces, robots, computers, offices, money, blue, purple, visual clutter, glitch artifacts, literal particle effects in the still, black background.

## Rules
- Best practice: clear, concise, non-texty. If text must appear, write it EXACTLY as it should render + placement + effects.
- One message per frame. Layered for independent motion.
- Arabic in-image text is rendered by CODE (crisp), not by the image model, unless the prompt explicitly includes exact Arabic strings.
